## 📌 Sobre esta entrega

Esta pasta contém o sistema de monitoramento interativo da plataforma SolarGuard. O programa lê os dados dos ciclos satelitais, organiza as informações em vetores e estruturas condicionais, e oferece um menu interativo para análise e histórico de leituras.

## 🎯 Funcionalidades

- Inserção e simulação de dados por sensores
- Verificação automática de condições críticas:
  - Temperatura > 80°C → alerta de superaquecimento
  - Energia < 20% → modo economia de energia
  - Comunicação = 0 → falha de comunicação
- Menu interativo com: inserir dados, visualizar status, análise, histórico e encerrar
- Histórico completo de todas as leituras realizadas
