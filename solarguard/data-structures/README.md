Menu interativo de monitoramento dos ciclos de dados satelitais. Permite inserir leituras, visualizar o status atual, executar análise de condições críticas e consultar o histórico de ciclos anteriores.

Condições verificadas: superaquecimento (temp > 80°C), bateria crítica (< 20%) e falha de comunicação.
