# SolarGuard

Global Solution 2026.1 — FIAP 1CCPY | Grupo 5

---

O SolarGuard é uma plataforma de inteligência energética que usa dados de irradiância solar coletados por satélites públicos (NASA POWER, Copernicus/ESA, INPE) para monitorar condições operacionais e gerar alertas e recomendações automáticas.

A conexão com o tema Space Connect está no insumo principal da plataforma: sem os dados que satélites em órbita coletam gratuitamente, o sistema não funciona.
