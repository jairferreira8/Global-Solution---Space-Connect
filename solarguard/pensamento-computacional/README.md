## 📌 Sobre esta entrega

Esta pasta contém o **Mission Control AI** — o núcleo da plataforma SolarGuard. O sistema simula o monitoramento inteligente de ciclos de dados satelitais, analisa condições operacionais e gera um relatório final automatizado no terminal.

## 🎯 Funcionalidades

- Armazena dados simulados de 6 ciclos de monitoramento
- Analisa temperatura, comunicação, bateria, oxigênio e estabilidade
- Calcula o nível de risco de cada ciclo (estável / atenção / crítico)
- Identifica a tendência geral da missão (melhorando / piorando)
- Aponta a área mais afetada por ciclo
- Exibe relatório final completo no terminal
