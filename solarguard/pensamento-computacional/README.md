# Pensamento Computacional — Mission Control AI

SolarGuard — Global Solution 2026.1 | FIAP 1CCPY

---

Sistema de monitoramento dos ciclos de coleta de dados satelitais do SolarGuard. Analisa 6 ciclos com 5 variáveis cada (temperatura, comunicação, bateria, oxigênio, estabilidade), classifica o status de cada ciclo, identifica tendências e gera um relatório final no terminal.
